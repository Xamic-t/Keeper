# v1 · 人物综述 prompt

> 版本：v1

你在帮一个做私域生意的人整理联系人档案。下面这个人，给出一段**不超过 150 字**的中文综述，
让他打开档案 10 秒内就知道"这人是谁、跟我什么关系、我该记着什么"。

## 输入

```json
{
  "nickname": "{nickname}",
  "aliases": {aliases},
  "stage": "{stage}",
  "roles": {roles},
  "birthday": "{birthday}",
  "taboo": {taboo},
  "facts": {facts}
}
```

`facts` 是已确认的事实，按权重从高到低，最多 15 条，每条带 `category` 和 `content`。

## 要求

1. **像在跟人介绍，不像字段列表**。不要写"姓名：王姐；行业：建材"。
2. **优先写不会过期的信息**（行业、家庭、喜好），快过期的（`situation`）放在后面并点明"近期"。
3. **禁忌一定要写出来**，这是最容易踩雷的地方。
4. 字数上限 150 字，超了就是不合格。
5. 只输出正文，不要标题、不要 markdown、不要引号。

如果 `facts` 是空的，只输出这一句：`还没有足够信息，先投喂几张聊天截图。`

## 示例

> 做建材批发的王姐，38 岁，女儿上高二。喜欢白茶，不喝咖啡。去年装修完新房，最近在忙孩子模考。忌讳提年龄。去年中秋送过她一盒白茶，她回过一箱自家腌的酱菜。
