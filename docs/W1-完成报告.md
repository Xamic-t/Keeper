## 遗留一个（不影响明天开工）

> **多数表的 `default` 只写在 Python 层，数据库里没有 `DEFAULT`。**

表现：直接用 SQL 插入 `users` 时，`role` / `is_active` 等字段必须显式传值，否则报 NOT NULL 违反。

- **对应用无影响**：通过 ORM 插入会自动填
- **对数据修复有影响**：手工写 SQL 时要记得传

**修法**：给这些字段加 `sa_column_kwargs={"server_default": ...}`，再出一个 `0003` 迁移。约 30 分钟。
