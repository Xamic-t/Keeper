## 二、需要你决策的重写项

> 下面每一项都是**代码与 Architecture 原意不一致**，我没有擅自改代码，也没有再擅自改 Architecture 抹掉要求。

### D1 · PWA：Architecture 要求，代码没有

| 项 | 内容 |
|---|---|
| 依据 | `docs/ARCHITECTURE.md` 第 6 节架构图 `Vue 3 SPA + Tailwind + PWA`；第 5 节「响应式 Web + PWA 够用」 |
| 现状 | `frontend/` 没有 `manifest.webmanifest`、没有 service worker，`index.html` 也没有 PWA 配置 |
| 影响 | 手机不能“添加到主屏幕”当 App 用；断网无静态壳缓存。核心在线功能不受影响 |
| 选项 A（推荐，严格符合） | 加 PWA：manifest + 图标 + service worker（静态资源预缓存，`/api` 一律网络优先/不缓存）。需要新增 `vite-plugin-pwa`，先改 Architecture 7.6.1 再改代码 |
| 选项 B（改需求） | 正式从 V1 移除 PWA，Architecture 改为“响应式 Web”，并同步 docs/02、docs/04。**这不是补代码，是降范围，需要你签字** |
| 我的建议 | 选 A。PWA 是“像 App”的最低成本实现；B 会让 Architecture 与答辩叙事里的“手机优先”变弱 |

### D2 · Harness 自带 Web UI：Architecture 说不用，代码在用

| 项 | 内容 |
|---|---|
| 依据 | `ARCHITECTURE` 19.7.6：「自带 Web UI ❌ 我们有自己的 Vue 前端」 |
| 现状 | `frontend/src/views/AssistantView.vue` 用 iframe 嵌 dsh Web UI；token 地址存 `sessionStorage` |
| 影响 | 当前助理能最快跑起来；但与 Architecture 的“自己写 Vue 界面”相反，且 iframe 的 X-Frame-Options / token 地址都是外部依赖 |
| 选项 A（推荐，改架构） | 承认“V1 用 dsh Web UI 作为助理界面”，Architecture 19.7.6 改为 ✅（iframe + token 只存 sessionStorage），并写明 V2 再自研。成本低，当前已可用 |
| 选项 B（严格符合） | 删掉 iframe，自己做 Vue 对话页或只保留“新窗口打开”。需要重写助理交互，且会丢掉 dsh 的工具调用可视化 |
| 我的建议 | 选 A。Architecture 原句是“我们有自己的 Vue 前端”，但当前并没有自研助理前端；要么补，要么承认现实。不要两头都不认 |

### D3 · 单进程 vs 双进程：Architecture 原为单进程，代码拆了 scheduler

| 项 | 内容 |
|---|---|
| 依据 | v2.3 第 6 节：`Uvicorn + FastAPI（单进程）`，`jobs/` 在进程内 |
| 现状 | `docker-compose.yml` 有独立 `scheduler` 容器，`dev.sh` 也单独起 `daily --serve`；这是为修 P0「每日任务不触发」做的 |
| 影响 | 故障隔离更好：scheduler 崩了不影响 API，API 发布不打断定时器；代价是多一个进程要监控 |
| 选项 A（推荐，追认变更） | 接受双进程，Architecture 6.1 保留（已标“待追认”）；补 scheduler 日志/健康检查规范 |
| 选项 B（严格回到原架构） | 把 `daily --serve` 放回 FastAPI `lifespan`，删 scheduler 容器。部署更简单，但 API 重启会打断定时器，且多 worker 时会重复跑 |
| 我的建议 | 选 A。单进程跑 APScheduler 在多 worker 下会重复触发，和“提醒幂等”不是一回事；双进程是对的 |

### D4 · 离线回放：V1 验收要求，代码没有

| 项 | 内容 |
|---|---|
| 依据 | `docs/02-产品设计.md` §6.4 标 **V1**；`docs/04-计划与验收.md` W18 和“演示稳定性”都要求离线回放 |

| 选项 A（推荐，符合 V1） | 加 `DEMO_MODE` / fixture：预录 3–5 条抽取结果、提醒文案、日历数据，断网时前端走本地 fixture，不调模型。需要新依赖/开关，先改 Architecture |
| 选项 B（降范围） | 明确离线回放推到 V2，答辩用录屏兜底。需要同步 docs/02、docs/04，不能只在报告里说 |
