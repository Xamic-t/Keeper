**覆盖率没到 90% 的原因不是没写测试，而是三类分支需要外部条件**：
- 真实模型调用（抽取、综述、提醒文案）：用 monkeypatch 或 e2e 覆盖成功路径，失败/超时分支只在单测里假造；
- 真实推送（企微/PushPlus）：无 token，接口只测参数校验与“未配置”降级；
- 定时调度常驻循环：容器行为，单测只测 `run_once()`，`_serve()` 属部署验证。

