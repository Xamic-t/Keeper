# 33 · 助理整合交付报告（2026-11-03 凌晨第二批）

> 对应计划：`docs/32-助理整合计划.md`
> 一句话：**助理从"另起一个服务 + iframe + 藏在设置里"改成了主界面一级菜单里的原生对话，
> 能发文字/图片、能问问题、能一句话建待办和事件。**

---

## 一、先回答你提的三个问题

| 你的疑问 | 之前为什么这样 | 现在怎么做 |
|---|---|---|
| **为什么要单独启动？** | 助理是 DeepSeek Harness 侧车：一个 Node 容器跑 dsh，主站只是 iframe 嵌它 | **不再需要任何额外启动**。助理就是主服务的一个页面 + 一个接口，`./start.sh` 起来就能用 |
| **什么叫"保存并打开"？** | dsh 的 `?token=` 每次重启都变，所以要你手粘一次地址存进 sessionStorage | 这套逻辑连同页面一起删了。**没有 token、没有 iframe、没有"打开"这一步** |
| **为什么藏在设置里？** | 手机上底部 tab 已有 6 个，当时判断"再加就挤"，于是助理只在桌面侧栏、手机绕设置进 | **助理现在是第三个一级菜单**（今日 · 投喂 · **助理** · 人 · 确认 · 日历 · 待办），桌面和手机都有 |

## 二、做了什么

### 1. 前端：新的「助理」页（自研聊天）

| 能力 | 实现 |
|---|---|
| 聊天窗口 | 用户气泡靠右、助理靠左；Enter 发送 / Shift+Enter 换行 |
| 等在模型时 | 立刻上气泡 + "正在想…"，不让你盯着没反应的输入框 |
| 发图片 | 📎 选图 → 本地预览可撤 → 上传后走既有投喂流水线（识别 → 进确认队列） |
| 动作可见 | 助理干完活，气泡下面一条「☑ 已创建待办：… **去看待办**」，能直接点过去 |
| 失败可重试 | 消息留在原地 + 「重试」，不静默丢失 |
| 历史 | 刷新/换设备还在；右上角「清空对话」（只清对话，不删已建的待办） |
| 空状态 | 三个能直接点的例子（建待办 / 问喜好 / 问这周要准备什么） |
| 手机 | 底部 tab 有助理；390px 宽度下不挤、输入框不溢出 |

**删掉的**：`AssistantView.vue`（iframe 版）、`VITE_HARNESS_URL` 的用法、`desktopOnly` 那套"只有桌面能进"的逻辑。

### 2. 后端：真模型对话 + 动作执行

新增 `POST/GET/DELETE /api/conversation/messages`（和旧的投喂对话框 `/api/chat` 并存，职责分开）。

一轮对话的执行顺序：

```
用户消息先落库  →  拼上下文（今天/人物名录/7 天内事件/今天该做的待办）
   →  调模型（复用 VisionClient 的主备双通道）
   →  校验 {reply, actions[]}
   →  执行白名单动作（最多 3 个）
   →  助手消息 + 动作结果落库
```

**动作白名单**（只允许这三类，删改一律不做）：

| 动作 | 落到哪 | 安全设计 |
|---|---|---|
| `create_todo` | `todos`（`source=ai`，带 `ai_reason`） | 标题必填；人名认不出就不挂人 |
| `create_event` | `events`（生日/结款/节日/自定义） | 生日和结款**必须挂到人**，否则不建 |
| `add_fact` | `facts`，**`status=pending`** | AI 不许直接写档案，只能进确认队列等你点 |

**可靠性**：模型偶尔不按 JSON 回（实测遇到过一次）。对话这条链路加了一次"不合格就重发"，
但仍然**不做格式修复**；两次都不行就返回 502，前端给你「重试」。
（抽取出那条链路保持原样：不是 JSON 直接判失败，因为那条宁可失败也不能猜。）

## 四、遗留与需要你决定的

| 项 | 现状 | 建议 |
|---|---|---|
| 会话保留多久 | 现在**永久保留**，只能手动清空 | 是否需要"只留最近 30 天"？见 `docs/29` D-6 |
| Harness 侧车是否下线 | 保留在 `docker-compose.yml` 的 `assistant` profile 里，默认不启、前端零依赖 | 建议先留一个月（`docs/29` D-7） |
| 助理能不能改数据（改阶段、删待办） | **不做**。白名单只有"新建" | 真要放开，必须先设计"改动进确认队列"，见 19.7.10 |
| 语音输入 / 多会话 | 不做 | V2 |
| 模型偶尔不按 JSON | 已加一次重试；仍失败就是 502 + 前端重试 | 观察一周，若频繁再考虑换 function-calling |

## 五、明早怎么用

```bash
./start.sh                 # 起服务（助理已经在这套里，不用额外起什么）
```

浏览器开 <http://127.0.0.1:5173> → 点导航第三个 **助理** → 直接说：

- `11 月 4 号王姐生日，帮我建个待办`
- `王姐喜欢什么？`
- `这周还有哪些日子要准备？`
- 或者 📎 发一张聊天截图，它会先识别、再告诉你抽到了什么

**注意**：你说的"王姐"必须是系统里已经有的人（昵称或别名）。没有的话它会问你要建哪一个，
不会自己编一个人出来。
