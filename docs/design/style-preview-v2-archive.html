  • 标题衬线（Songti SC），正文黑体，数字与编号等宽
  • 三层足矣：Display 32-40 / Body 13.5-16 / Meta 9.5-10.5

结构与留白

  • 不用卡片，用横线切分区块
  • 区块间距 22-30px，条目内间距 8-10px
  • 页面左右留白 20px（手机）
  • 圆角只有两种：1px（按钮/标签）和 14px（设备外壳）
  • 阴影只给浮层（便笺、弹窗），列表项一律无阴影

层级建立方式

  • 字号：38 → 17 → 13.5 → 10
  • 字体族：衬线标题 / 黑体正文 / 等宽元数据
  • 横线：实线 1px #1C1A15 分大区块，细线 #D5CEBF 分条目
  • 不用：阴影、渐变、图标、彩色背景块

颜色纪律

  • 朱红 #A63A2B 只用于：编号、印章、今日导航、低置信度
  • 墨绿 #4A5D52 只用于「已完成 / 已结清」
  • 其余全部是纸与墨的明度变化
  • 一屏之内朱红出现不超过 4 次

那个章

  • 确认一条事实 → 盖「已记」
  • 提醒转成待办 → 盖「待办」
  • 章是斜的、有边框、半透明，像手盖的
  • 它不参与布局，浮在角落，不挡信息
