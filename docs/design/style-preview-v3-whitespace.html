结构纪律

  • 不用卡片——分组只靠留白和一条 1px 细线
  • 区块间距 44–64px，条目内 6–12px
  • 页面左右留白 24px
  • 圆角只用两处：设备壳 16px、按钮胶囊
  • 零阴影、零渐变（唯一例外是设备壳的投影，那是展示需要）

颜色纪律

  • 主色 #2F4F45 只用于：主按钮、当前导航、下划线标记
  • 赭 #B65A3C 只用于：序号、低置信度、提醒标题。全屏 ≤3 处
  • 其余全部是墨与线的明度差
  • 不用颜色区分人物，用文字

一屏一个重心

  • 今日页：「今天 / 两件事」是第一眼，其他都是次要
  • 档案页：名字是第一眼，摘要第二，其余第三
  • 提醒卡：建议是第一眼，依据第二，话术第三
  • 层级靠字号和位置，不靠颜色堆叠

克制 ≠ 少放信息

  • 克制的是手段：颜色数、字重数、装饰手法
  • 不克制信息：金额、日期、出处一个都不能少
  • 每条事实必须能点开看原图
  • 提醒必须带依据——这条永不妥协
